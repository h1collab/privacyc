# Zorixos — Introduzione (Italiano)

Benvenuto in Zorixos, una replica web di macOS costruita dentro questo repository. Qui trovi una panoramica delle funzionalità principali e come provarle.

- Animazione di avvio in stile macOS (con rimozione del cursore durante l'avvio).
- Desktop con Dock, menu bar, icone e finestre rimovibili.
- Utility di cifratura locale (AES-GCM + PBKDF2) per crittografare testi nel browser.

Consulta ZORIXOS_FEATURES_IT.md per la lista completa delle funzionalità.
