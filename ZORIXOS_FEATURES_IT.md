# Funzionalità di Zorixos (Italiano)

1. Boot: Animazione di avvio con logo e barra di progresso. Il cursore è nascosto durante il boot.
2. Desktop: Icone, gestione finestre, titolo e barra di controllo.
3. Dock: Lanciatore veloce per app demo: Finder, Notes, Encrypt.
4. Crittografia: Esempio locale che usa Web Crypto API per AES-GCM con derivazione chiave PBKDF2.

Vedi ZORIXOS_QUICKSTART_IT.md per le istruzioni rapide.
