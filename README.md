# privacyc - Zorixos (macOS-like web desktop)

This repository has been converted into "Zorixos": a macOS-inspired web desktop experience that runs as a static site. The site includes a macOS-like boot animation, a desktop with windows and Dock, and local encryption utilities using the Web Crypto API.

Note: This project reproduces the look-and-feel of macOS in the browser. It is not an operating system — system-level features (kernel, drivers, real hardware access) cannot be reproduced in a web page.

See ZORIXOS_IT.md for an Italian introduction to all features.
